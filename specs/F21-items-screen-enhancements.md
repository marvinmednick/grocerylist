## Feature: Items Screen Enhancements

### Context

The master Items screen (`app/(tabs)/items.tsx`) currently shows all items in fixed A→Z order with only a text search filter. Three improvements are batched here:

1. **Sort controls** — let users sort by name (A→Z / Z→A) or creation date (Newest / Oldest).
2. **Recently Added filter** — a toggle that shows only items created in the last 7 days, making it easy to find items auto-created by quick-add and fill in missing details.
3. **"New" badge** — a small blue pill on item cards for items created within the last 7 days, surfacing new additions passively.

Issue: [#64](https://github.com/marvinmednick/grocerylist/issues/64)

**Update `useAllItems` signature and query:**

```typescript
export const useAllItems = (searchTerm: string = '', sort: SortOption = 'name_asc') => {
  return useQuery({
    queryKey: ['all_items', searchTerm, sort],
    queryFn: async () => {
      let query = supabase
        .from('items')
        .select(`
          *,
          category:categories!default_category_id(name),
          item_store_preferences(
            store_id, status, comment,
            store:stores(id, name, color_code)
          )
        `);

      // Apply sort
      if (sort === 'name_asc') query = query.order('name', { ascending: true });
      else if (sort === 'name_desc') query = query.order('name', { ascending: false });
      else if (sort === 'created_desc') query = query.order('created_at', { ascending: false });
      else if (sort === 'created_asc') query = query.order('created_at', { ascending: true });

      if (searchTerm.length > 0) {
        query = query.ilike('name', `%${searchTerm}%`);
      }

      const { data, error } = await query.limit(100);
      if (error) throw error;
      return data as MasterItem[];
    },
    staleTime: 60 * 1000,
  });
};
```

The `staleTime` value should match whatever the existing hook uses — do not change it.


### Acceptance Criteria

- Four sort pills (A→Z, Z→A, Newest, Oldest) and a Recent toggle appear below the search bar.
- The active sort pill is highlighted (blue background, white text); inactive pills are gray.
- Tapping a sort pill updates the list order immediately.
- Default sort on screen open is A→Z.
- Tapping "Recent" toggle activates it (blue) and filters list to items created within the last 7 days; it also sets sort to Newest.
- Tapping "Recent" again deactivates it and shows all items (sort stays at current value).
- Recent filter is ANDed with text search: if both are active, only items matching both are shown.
- Items created within the last 7 days show a small blue "New" badge on their card.
- Items created more than 7 days ago do not show the badge.
- All existing items/search/modal functionality is unaffected.
