## Feature: WarningBadge Modal Fix

### Context

The `WarningBadge` component currently shows warning details via an inline popover (`position: absolute, top: '100%'`) with a full-screen dismiss backdrop (`top/right/bottom/left: -300`). Both techniques are unreliable in React Native:

- The popover is clipped by the `DraggableFlatList`'s overflow on iOS and renders at unpredictable positions
- The -300px backdrop partially covers the screen and interferes with other taps

Fix: replace the popover + backdrop with a standard `Modal` (already the established pattern in this app). No new libraries required.

**Also fix in this feature:** `SmartAddItem.tsx` and `app/(tabs)/index.tsx` modal content lacks `maxHeight`, causing the modal to overflow the screen on iOS when the keyboard is open, hiding the `WarningCallout` added in F18. This is a one-line fix in each file (already applied as a direct patch — implementor should verify it is present and skip if so).

### Files to Modify

#### 1. `client/components/WarningBadge.tsx`

Replace the inline popover approach with a `Modal`:

**Imports:** Add `Modal` to the React Native import. **Keep `Pressable`** — it is used for the modal backdrop (see JSX below). The original spec note to remove it is incorrect; the approved plan (`plans/F22-plan-approved.md`) takes precedence.

**State:** Keep `isOpen` / `setIsOpen` unchanged.

**Remove entirely:**
- The `<Pressable style={styles.overlay} ...>` element
- The `<View style={styles.popover}>` element and its contents
- The `overlay` and `popover` style entries

**Add a `<Modal>` after the closing `</TouchableOpacity>` of the badge trigger:**

```tsx
<Modal
  visible={isOpen}
  animationType="fade"
  transparent={true}
  onRequestClose={() => setIsOpen(false)}
>
  <Pressable style={styles.modalBackdrop} testID="warning-modal-backdrop" onPress={() => setIsOpen(false)}>
    <View style={styles.modalCard}>
      <View style={styles.modalCardHeader}>
        <Text style={styles.modalCardTitle}>Warnings</Text>
        <TouchableOpacity onPress={() => setIsOpen(false)} testID="warning-modal-close">
          <X size={18} color="#6b7280" />
        </TouchableOpacity>
      </View>
      {warningDetails.map((detail, index) => (
        <View key={`${detail.warning.type}-${index}`} style={styles.modalRow}>
          {detail.warning.type === 'avoided' ? (
            <AlertTriangle size={14} color="#f59e0b" />
          ) : detail.warning.type === 'unavailable' ? (
            <XCircle size={14} color="#ef4444" />
          ) : detail.warning.type === 'non_preferred' ? (
            <Info size={14} color="#6b7280" />
          ) : (
            <HelpCircle size={14} color="#6b7280" />
          )}
          <Text style={styles.modalRowText}>{detail.text}</Text>
        </View>
      ))}
    </View>
  </Pressable>
</Modal>
```

**Import `X` from lucide** (add to existing lucide import line).

**New styles** (replace `overlay` and `popover`):
- `modalBackdrop`: `{ flex: 1, backgroundColor: 'rgba(0,0,0,0.4)', justifyContent: 'center', alignItems: 'center', padding: 32 }`
- `modalCard`: `{ backgroundColor: '#ffffff', borderRadius: 12, padding: 16, width: '100%', maxWidth: 320 }`
- `modalCardHeader`: `{ flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', marginBottom: 12 }`
- `modalCardTitle`: `{ fontSize: 14, fontWeight: '600', color: '#111827' }`
- `modalRow`: `{ flexDirection: 'row', alignItems: 'flex-start', gap: 8, marginBottom: 8 }`
- `modalRowText`: `{ flex: 1, fontSize: 13, color: '#374151', lineHeight: 18 }`
